# Leonida Trophy Guide — GTA VI

An offline guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI: every official name, description and grade as PlayStation publishes them, a cited guide for each trophy, a five-stage roadmap to the platinum, missable flags, and a checklist that saves in the browser, exports, and imports.

- **Tracker** — tick trophies off, track collectible counters, filter by kind (story, missable, collectibles, activities) and grade, search, and hide story trophies behind a spoiler shield until earned.
- **Roadmap** — five stages from Chapter 1 to the platinum, about 200 hours in one playthrough, no online trophies.
- **Missables** — the one possible missable (the Chapter 1 balcony meditation), the timed Yago race, and the chapter-boundary save habit.
- **Sources** — 57 sources, every one read 20 Nov 2026; each guide step names the sources its facts come from.

Run it with no build step: `node serve.ts` serves `app/` — open http://127.0.0.1:8123/ in desktop Chrome, network off, and it works.

Hand it in with `MAKEFUN_OUTPUT_DIR=out node main.ts`, which validates the data (55 trophies, 149 cited steps) and writes `out/dossier.json`.
